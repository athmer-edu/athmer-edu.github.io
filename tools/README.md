# أدوات بناء منصة أثمر (لا تُعرض للطالبات)
- `decks-env/`: مصادر عروض العلوم البيئية. البناء من جذر المستودع: `python3 tools/decks-env/build.py e11 e12 e13a e13b` (يأخذ محرّك العرض من slides/chem10-2-1.html و js/envart.js).
- `decks-chem/`: مصادر عروض الكيمياء التي بناها Claude.
- `tests/`: اختبارات Playwright (تحتاج تعديل المسارات إلى مكان نسخة المستودع): `mix.py <درس>` يلعب كل المستويات آليًا، و`dk.py <عرض>` يفحص فيض الشرائح، و`gall.py` للمستويات القديمة والأسئلة.
